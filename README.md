# ArcOS Installer

## EN
This installer is fork for [linexin-installer](https://github.com/Petexy/linexin-installer) prepared for ArcOS. My program have modifications:

- Another, new desktop environments avalible (cinnamon and hyprland)
- Modificated installation process

### WARNING
Do not choose Other desktop environments other than Plasma at this time. Theese options is not working (kernel panic, no GRUB etc.). I still working on it

### Dependencies:
- python-gobject
- python-cairo
- gtk4
- libadwaita
- python
